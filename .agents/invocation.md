# Кем вызывается скилл

Скиллы делятся по тому, кто может их запустить.

**Model-invoked** — агент дотягивается до них сам, когда задача подходит, и человек тоже может
позвать руками. Такие скиллы держат в себе разовую дисциплину: как поступать в этом типе
ситуации. Всё, что сейчас в репозитории, — model-invoked.

**User-invoked** — доступны только человеку, набравшему `/имя`. Их дело — оркестровать: вести
человека по шагам, задавать вопросы, звать другие скиллы. Такой скилл помечается
`disable-model-invocation: true` во фронтматтере.

Правило сочетания: user-invoked может звать model-invoked, но не другой user-invoked — иначе
человек теряет управление и не понимает, кто из них сейчас говорит.

## Что это значит для `description`

У model-invoked скилла `description` — единственное, по чему модель решает открывать его или нет.
Он должен содержать **поводы словами человека**, а не терминами скилла: «уходит», «ложится
спать», «доделай без меня» — это поводы; «переводит сессию в неинтерактивный режим» — термин,
по которому скилл не найдут.

У user-invoked описание может быть суше: его всё равно вызывает человек, который уже знает,
чего хочет.
