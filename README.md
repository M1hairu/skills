# claude-skills

Скиллы для [Claude Code](https://claude.com/claude-code). Ставятся симлинками: правка файла
в репозитории действует сразу, без переустановки.

## Что здесь есть

| Скилл | Зачем | Что приносит с собой |
|---|---|---|
| [afk](skills/afk) | Перевести идущую сессию в автономный режим, когда человек уходит: план работ, отсев человеко-зависимого, замыкание цикла | команды `afk`, `stayawake`; политика `~/.claude/afk-policy.md` |
| [vps-afk](skills/vps-afk) | То же, но работа уезжает на сервер и ноутбук можно выключить | команда `vps-afk`, [настройка](skills/vps-afk/SETUP.md) |

## Установка

```bash
git clone https://github.com/M1hairu/claude-skills.git ~/Documents/claude-skills
cd ~/Documents/claude-skills
./install.sh
```

Ставит всё; `./install.sh afk` — только названное, `--list` — посмотреть, что есть,
`--dry-run` — прогон вхолостую, `--uninstall` — снять.

Если по пути окажется настоящий файл, а не симлинк (например, у тебя уже лежит свой
`~/.local/bin/afk`), установщик его не тронет и скажет об этом. `--force` заменит, а старое
положит в `~/.local/state/claude-skills/backups/<дата>/` — в стороне от `~/.claude/skills`,
иначе каталог с бэкапом Claude Code принял бы за ещё один скилл.

Скиллы подхватываются в новой сессии Claude Code — перезапусти её после установки.
Проверить, что скилл виден: `/help` или прямой вызов `/afk`.

Требуется: `~/.local/bin` в `$PATH`, bash 4+, git. Команды скиллов рассчитаны на Linux
с systemd (`systemd-inhibit`, `systemd-run`); сами скиллы от системы не зависят.

## Как устроен репозиторий

```
skills/<имя>/
  SKILL.md      обязателен — сам скилл; каталог линкуется в ~/.claude/skills/<имя>
  bin/*         команды скилла → по одной в ~/.local/bin/
  claude/*      файлы окружения Claude → в ~/.claude/
  SETUP.md      если скиллу нужна разовая настройка руками
```

Установщик работает по этому соглашению и ничего не знает про конкретные скиллы: новый
скилл ставится тем же `./install.sh`, править `install.sh` не нужно.

## Добавить скилл

```bash
./scripts/new-skill.sh имя-скилла        # --bin, если нужна своя команда
$EDITOR skills/имя-скилла/SKILL.md
./scripts/validate.sh имя-скилла
./install.sh имя-скилла
```

`validate.sh` проверяет фронтматтер (`name` совпадает с каталогом, `description` на месте
и в пределах 1024 символов), синтаксис и права скриптов в `bin/`, объём `SKILL.md` — и ищет
следы личных данных: ключи, токены, адреса серверов, пути с чужим именем пользователя.
Репозиторий публичный, поэтому конфиги с адресами и секретами живут вне его,
в `~/.config/claude-skills/`.

Что писать в самом `SKILL.md` — в [template/SKILL.md](template/SKILL.md); там же напоминание,
что `description` важнее остального текста: по нему модель решает, звать ли скилл вообще.
