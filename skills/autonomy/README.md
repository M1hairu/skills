# autonomy

Работа, когда человека нет за компьютером.

**Model-invoked** — агент берётся за них сам, когда разговор к этому подходит; позвать руками
тоже можно.

- **[afk](./afk/SKILL.md)** — перевести идущую сессию в автономный режим: план работ, отсев
  человеко-зависимого, бюджет лимита, автономность без перезапуска, сторож на случай обрыва
  и замыкание цикла. Команды: `afk`, `stayawake`, `afk-limits`, `afk-autonomy`, `afk-watch`.
  [Документация](../../docs/autonomy/afk.md).
- **[vps-afk](./vps-afk/SKILL.md)** — вынести работу на сервер и отпустить ноутбук: код через
  git, секреты по rsync, прогон под `systemd-run`. [Документация](../../docs/autonomy/vps-afk.md),
  [настройка](./vps-afk/SETUP.md).
