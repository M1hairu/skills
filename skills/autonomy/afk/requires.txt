# Чем пользуются команды скилла. Строка: команда — зачем она нужна.
tmux — окно, которое переживает обрыв связи и в которое сторож может написать
curl — сторож проверяет по нему, вернулась ли связь
git — ночная работа коммитится мелкими шагами
python3 — разбор JSON: лимиты подписки, список сессий, решения хука
