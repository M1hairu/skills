# memory

Что агент помнит между сессиями и где это лежит.

**Model-invoked** — агент берётся за них сам, когда разговор к этому подходит; позвать руками
тоже можно.

- **[vault](./vault/SKILL.md)** — хранилище знаний в `~/vault`: связные заметки о проектах,
  системах и людях, которые человек открывает в Obsidian, общие с сервером через приватный git.
  Здесь же граница с машинной памятью Claude Code и с личным волтом человека — их скилл
  не трогает. [Документация](../../docs/memory/vault.md), [настройка](./vault/SETUP.md).
